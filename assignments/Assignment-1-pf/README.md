## Assignment Overview

This repository includes individual C++ files addressing various basic logical and mathematical problems. Below is a breakdown of the included programs:

*   **`question1.cpp` - Variable Assignment:** A program utilizing an if/else statement to assign `0` to `x` when `y` is equal to `10`, and `1` otherwise[cite: 1].
*   **`question2.cpp` - Temperature Validation:** An if statement that verifies if a `temperature` variable falls within the valid range of `-50` through `150`[cite: 2].
*   **`question3.cpp` - Number Comparison:** A script that takes two numerical inputs from the user and identifies which is larger, which is smaller, or if they are equal[cite: 3].
*   **`question4.cpp` - Floating-Point Modification:** A program that assigns the value `10.0` to two variables, adds `0.2` to one, and evaluates which value is larger[cite: 4].
*   **`question5.cpp` - Safe Division:** A program that divides two numbers while explicitly checking the denominator to ensure division by zero does not occur[cite: 5].
*   **`question7.cpp` - Race Standings:** A script that accepts the names and completion times (in minutes) of three runners, ranking them in first, second, and third place[cite: 6].
*   **`question8.cpp` - Geometry Calculator:** An interactive menu-driven program that calculates the area of a circle, rectangle, or triangle based on user selection[cite: 7].
*   **`Question9.cpp` - ASCII Display:** A loop-based program that displays the ASCII integer values for both uppercase and lowercase alphabets utilizing explicit type casting[cite: 8].
*   **`Question10.cpp` - Mass & Weight Calculator:** A script that calculates weight in Newtons from a given mass (using a multiplier of 9.8) and flags the object as "too heavy" if it exceeds `1000` Newtons or "too light" if it is below `10` Newtons[cite: 9].
